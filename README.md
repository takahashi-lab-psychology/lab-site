# 研究室サイト

ブラウザだけで運用できる静的サイトです。ビルド作業やソフトのインストールは要りません。

## ファイルの役割

| ファイル | 中身 | 編集するか |
|---|---|---|
| `assets/content.js` | 文章・お知らせ・論文・メンバー | **ここだけ編集します** |
| `assets/style.css` | 色や文字などのデザイン | 色を変えるときだけ |
| `assets/site.js` | ページの組み立て処理 | 触りません |
| `assets/orcid.js` | ORCIDからの自動取得 | 触りません |
| `assets/analytics.js` | アクセス解析の読み込み | 触りません |
| `*.html` | 各ページの入れ物 | 触りません |
| `images/` | 写真・図（自分で作るフォルダ） | 画像を足すとき |

## 更新のしかた

1. GitHub でリポジトリを開く
2. `assets` → `content.js` をクリック
3. 右上の鉛筆アイコン（Edit this file）を押す
4. 書き換える
5. 下の緑のボタン **Commit changes** を押す
6. 1〜2分待つとサイトに反映される

### お知らせを1件足す

`news:` の `[` のすぐ下に、この形で1行足します。場所はどこでも構いません（自動で新しい順に並びます）。

```js
{ date:"2026-09-15", ja:"日本語の本文", en:"English text" },
```

英語を書かない日は `en:""` のままで大丈夫です。日本語版が代わりに表示されます。

### 論文を1本足す

`publications:` の中に足します。

```js
{ year:2026,
  authors:"Yamada T, Suzuki H",
  title:"論文のタイトル",
  venue:"Journal Name 12:345-356",
  note:{ ja:"", en:"" },
  doi:"https://doi.org/...", pdf:"" },
```

著者名を `highlight:` のリストに入れておくと、自動で太字になります。

### ORCIDから自動で取り込む

自動取得は**最初からオンになっています**。あとは `content.js` に自分のORCID iDを入れるだけです。

```js
orcid: {
  enabled: true,
  id:      "0000-0002-1825-0097",   // ← ここに自分のIDを入れる
  since:   0,                       // この年以降だけ取り込む（0で全部）
  exclude: []                       // 別人の論文が混ざったらDOIをここに
},
```

IDが空の間は同期は始まらず、手動リストだけが表示されます。ページが壊れることはありません。

自動取得と手動リストは**併用できます**。両方に同じ論文があるときは、DOIで重複を判定して**手動で書いたほうが優先**されます。ORCID由来の表記が気に入らない論文だけ、手動で書き直せばそちらが使われます。

- ORCIDは著者リストを持っていないため、著者名と巻号はCrossrefから補います
- 結果は24時間ブラウザに保存され、毎回取りに行くことはありません
- **取得に失敗しても手動リストは必ず表示されます**
- ORCIDに未登録の論文（DOIのない発表など）は手動で足してください

#### うまくいかないとき

論文ページのURLの末尾に `?debug` を付けて開いてください。

```
https://ユーザー名.github.io/lab-site/publications.html?debug
```

同期の状況（何件取れたか、なぜ失敗したか）が画面に表示されます。この表示は `?debug` を付けたときだけ出るので、訪問者には見えません。

### メンバーが増えたとき / 抜けたとき

増えたら `members:` に足します。抜けたら、その項目を `members:` から `alumni:` に移します。消さないでください。

### 写真を入れる

1. リポジトリのトップで **Add file → Upload files**
2. 画像をドラッグして Commit
3. `content.js` で `photo:"images/suzuki.jpg"` のように指定

正方形に切り抜かれるので、顔が中央に来る写真がきれいです。

## アクセス解析

`content.js` の `analytics:` で設定します。初期状態はオフです。

```js
analytics: {
  provider:   "none",   // "none" / "ga4" / "cloudflare" / "goatcounter"
  id:         "",
  respectDNT: true      // Do Not Track を送るブラウザは解析しない
},
```

| provider | id に入れるもの | Cookie | 同意バナー |
|---|---|---|---|
| `"ga4"` | `G-XXXXXXXXXX`（測定ID） | 使う | 必要 |
| `"cloudflare"` | Cloudflareが発行するトークン | 使わない | 不要 |
| `"goatcounter"` | `https://○○.goatcounter.com/count` | 使わない | 不要 |

GA4を選んだ場合、IPの匿名化と広告目的でのデータ利用の停止は自動で設定されます。ただし、それでもプライバシーポリシーの掲示は必要です。

`respectDNT: true` のとき、ブラウザがDo Not Trackを送っていれば解析スクリプト自体を読み込みません。

## 壊れたとき

ページに赤い枠で案内が出たら、`content.js` の書き間違いです。多いのは次の3つ。

- 行末の **カンマ `,`** を消してしまった
- **引用符 `"`** が片方だけになっている
- **`{ }` や `[ ]`** の数が合っていない

直せないときは、GitHub の **History**（コミット履歴）から編集前の状態に戻せます。何をしても元に戻せるので、恐れずに編集して構いません。

## 表示の設定

`content.js` の先頭にあります。

```js
settings: {
  topNewsCount:  3,     // トップに出すお知らせの件数
  topNewsMaxAge: 365,   // これより古いお知らせはトップに出さない（日数／0で無制限）
  defaultLang:   "ja"   // 最初に表示する言語
}
```

## 色を変える

`assets/style.css` の上のほうにある `--accent` の値を変えます。

```css
--accent:#8c2f39;       /* 現在: 臙脂 */
```

ネイビー `#23395B` / 深緑 `#2C4A3E` / 藍 `#1F3A63` などが同じトーンで置き換わります。すぐ下の `--accent-deep` も少し暗い同系色にしておくと自然です。

## 動作確認

`index.html` をダブルクリックすれば、手元のパソコンでもそのまま開けます。サーバーは不要です。
